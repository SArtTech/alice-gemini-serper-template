# Эдит ИИ — Яндекс Станция + Gemini + Serper

Персональный навык Яндекс Алисы, который использует **Gemini для голосовых ответов** и **Serper для свежих данных из интернета**. Работает на Vercel Functions без своего сервера.

## Текущий проект

- GitHub: https://github.com/SArtTech/alice-gemini-serper-template
- Vercel: https://vercel.com/kodx1/alice-gemini-serper-template
- Production: https://alice-gemini-serper-template-kodx1.vercel.app
- Health check: `GET /api` — `{ "ok": true, "service": "edith-ai", "version": "2.0" }`

## Настройка навыка «Эдит ИИ»

В [Яндекс Диалогах](https://dialogs.yandex.ru/developer) откройте уже созданный навык **Эдит ИИ**.

1. В разделе **Backend → Webhook URL** укажите `https://alice-gemini-serper-template-kodx1.vercel.app/api?token=СЕКРЕТ_ИЗ_VERCEL`. Секрет должен точно совпадать со значением `ALICE_WEBHOOK_SECRET`.
2. Включите **Хранилище → Использовать хранилище данных в навыке**, иначе краткий контекст между фразами не сохраняется.
3. Проверьте, что доступ **приватный**, а типы устройств включают Яндекс Станцию.
4. В разделе тестирования запустите навык. Для голосового запуска используйте «Алиса, запусти навык Эдит ИИ». Для приватного навыка Станция должна быть авторизована в том же Яндекс ID.
5. Если захотите усилить проверку источника запросов, сохраните ID навыка из Яндекс Диалогов в переменную `ALICE_SKILL_ID` на Vercel и заново разверните проект.

## Обязательные переменные окружения Vercel

| Переменная | Назначение |
| --- | --- |
| `GEMINI_API_KEY` | Google AI Studio, ключ для Google Gemini |
| `SERPER_API_KEY` | Serper.dev, ключ для интернет-поиска |
| `ALICE_WEBHOOK_SECRET` | Длинный случайный секрет; совпадает с параметром `token` в настройках Яндекс Диалогов |
| `GEMINI_MODEL` | Опционально: `gemini-3.5-flash-lite` |
| `ALICE_SKILL_ID` | Опционально: точный UUID навыка |

**Никогда не записывайте ключи и секреты в GitHub, код или README.** Значения храните только в Vercel → Project Settings → Environment Variables и в приватных настройках вебхука Яндекса.

## Особенности работы

- Запуск навыка возвращает приветствие «Привет! Я Эдит ИИ» немедленно, без внешних API.
- Обычные вопросы передаются Gemini, вопросы о новостях и актуальной информации дополнительно используют Serper.
- Функция ограничивает время ответа и даёт понятный резервный ответ, если внешние API не успели.
- `session_state` ограничивается 940 байт (1 КиБ лимит Яндекс Диалогов на JSON-состояние).
- Отправка сообщений `POST /api` требует `?token=...`. Запросы без секрета получают 404, **не расходуя Gemini API**.
- `GET /api` выполняет бесплатную проверку доступности. Административные `GET /api?probe=gemini&token=...` и `GET /api?probe=serper&token=...` проверяют соответствующие API и расходуют небольшой лимит; не открывайте их посторонним.
- Время ожидания Яндекс Диалогов — **4,5 сек**, включая сеть. Даже при успешной работе бывают ошибки на длинных запросах.

## Диагностика

1. Запросите `GET /api`. Если вебхук не отвечает, проверьте сборку и домен в Vercel.
2. Если тестер Яндекса сообщает 403/404, проверьте Webhook URL вместе с параметром `token` и доступность Production без защиты Vercel Authentication.
3. Если стартовое приветствие есть, но обычные вопросы не работают, проверяйте Gemini через защищённый `probe=gemini` и логи Runtime на Vercel. Код не выводит API-ключи.
4. Если поиск не работает, проверяйте `probe=serper`. Тайм-аут поискового провайдера намеренно короткий.
5. Локальные тесты: `npm test`. Тесты также автоматически запускаются во время `npm run build` на Vercel.
